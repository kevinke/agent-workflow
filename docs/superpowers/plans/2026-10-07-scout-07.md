# Safe Workflow v2 Release and Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the complete v2 contract for new work and make existing Ticket conversion explicit and reconstructible.

**Architecture:** Separate protocol-file upgrade from Ticket-state conversion. Release the default only after 01–06; allow senior reconstruction at a retained phase using their normal artifact commands.

**Tech Stack:** Python 3 stdlib, unittest, Markdown/restricted YAML, Git.

**Spec:** [Feature spec](../../../.scratch/decision-scout-port/spec.md), Ticket SCOUT-007. **Blocked by:** 06.

## Global Constraints

Read [the common plan](2026-10-07-decision-scout-handoff.md), especially Reconstruction rule and limits.
"Stricter gates use workflow version 2, retaining schema version 1 and the restricted YAML subset."
"Version 1 Tickets retain their semantics until explicitly upgraded."
Never create historic sufficiency, completed contracts or a passing Review from scaffolds.

## Review Focus

Common case 5 belongs here: retained implementation/review must allow reconstruction.
Also test half-completed v1, historical done, unknown State maps, old installed
templates and dirty adoption; preserve bytes on rejected conversion.
