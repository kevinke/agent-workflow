# HARDEN-010: Index-flag-independent Review Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reject stale Review bindings even when Git index hints hide tracked edits or deletions, without changing the real index or losing racy-stat detection.

**Architecture:** Clear both hints only in the existing disposable index, then restore that copy's original nanosecond timestamp before the existing diff union runs. Keep the shared `code_drift` interface and route every consumer through it; unsupported assessment remains an error.

**Tech Stack:** Python 3 stdlib, Git, unittest; existing restricted YAML and public CLI fixtures.

**Spec:** [C2 follow-up and testing decisions](../../../.scratch/decision-scout-hardening/spec.md#index-flag-follow-up-harden-010).

**Ticket:** [HARDEN-010](../../../.scratch/decision-scout-hardening/issues/10-index-flag-independent-review.md). **Blocked by:** None. **Sequence:** precedes [011](2026-10-09-harden-11.md). This is a development plan, not a registered execution contract or test result.
