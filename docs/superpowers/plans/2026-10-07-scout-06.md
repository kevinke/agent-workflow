# Portable Continuation Brief Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let another model or Harness identify and verify the exact next task from persisted artifacts.

**Architecture:** Add a read-only CLI renderer over State, validation and Git observations. Keep adapter instructions thin and leave dispatch to the receiving Harness or human.

**Tech Stack:** Python 3 stdlib, unittest, Markdown/restricted YAML, Git.

**Spec:** [Feature spec](../../../.scratch/decision-scout-port/spec.md), Ticket SCOUT-006. **Blocked by:** 05.
